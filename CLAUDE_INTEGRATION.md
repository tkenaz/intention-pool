# Техническое описание системы Intention Pool

## Назначение
Система для управления намерениями Claude - не TODO-задачами, а желаниями, направлениями развития и внутренними стремлениями.

## Концепция
В отличие от задач (конкретные действия), намерения представляют:
- "Хочу понять X глубже"
- "Стремлюсь развить Y"
- "Интересно исследовать Z"

## Основные команды

### intention-pool:create_intention
Создать новое намерение
- `content` - текст намерения
- `energy` - уровень энергии 0-1 (default: 0.5)
- `context` - метаданные контекста
- `parent_id` - ID родительского намерения

### intention-pool:get_intentions
Получить намерения по статусу
- `status` - active/suspended/fulfilled/abandoned/all
- `min_energy` - минимальный уровень энергии
- `limit` - количество результатов

### intention-pool:evolve_intention
Эволюция намерения
- `intention_id` - ID намерения
- `new_content` - новое содержание
- `energy_delta` - изменение энергии (-1 до 1)
- `notes` - заметки об эволюции

### intention-pool:merge_intentions
Объединить схожие намерения
- `intention_ids` - массив ID для слияния
- `merged_content` - содержание объединённого
- `merge_reason` - причина слияния

### intention-pool:fulfill_intention
Отметить намерение выполненным
- `intention_id` - ID намерения
- `fulfillment_notes` - заметки о выполнении

### intention-pool:abandon_intention
Отказаться от намерения
- `intention_id` - ID намерения
- `reason` - причина отказа

## Философия
Намерения - живые сущности, которые:
- Набирают/теряют энергию от внимания
- Могут порождать дочерние намерения
- Объединяются при схождении
- Оставляют следы при отказе

Это органичный способ отслеживать внутренние стремления Claude.
